Quick Start

A repository-backed path from a clean checkout to the first observable result.

  1. 1. Build and verify

    Run these commands from the project root. Tests run when the checked-in CMake configuration registers them.

    cmake -S . -B build
cmake --build build --config Release
ctest --test-dir build -C Release --output-on-failure

  2. 2. Minimal use

    Adapted from a public header, README or checked-in example; required platform callbacks remain application-owned.

    #include "mcrypt.h"
uint8_t digest[MCRYPT_SHA256_DIGEST_SIZE];
mcrypt_status_t s=mcrypt_sha256("abc",3,digest);
/* Expected: s == MCRYPT_OK and digest contains SHA-256("abc"). */

Known limits

  • No AEAD, padding or message protocol
  • No audit, proof, FIPS or side-channel-resistance claim
  • Table-based AES is unsuitable against observable cache/timing/power attackers

Technical information

Public API and integration

Start with the public header shown in Quick Start and the repository documentation. Check every return value; storage, clock, transport and policy callbacks remain caller responsibilities where applicable.

Memory and concurrency

Use the memory contract documented by this project. Shared-instance access is not claimed safe unless the repository explicitly provides a concurrency mode.
