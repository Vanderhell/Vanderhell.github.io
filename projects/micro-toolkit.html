Quick Start

This minimum pattern is adapted from the repository README or public-header examples. Comments state the expected behavior; no terminal output is fabricated.

# Configure dependency source locations, then:
cmake -S . -B build -DMICRO_TOOLKIT_BUILD_EXAMPLES=ON
cmake --build build
# Expected: the configured integration example builds against supplied sources.

Technical information

Public API and integration

Start with the public header shown in Quick Start and the repository documentation. Check every return value; storage, clock, transport and policy callbacks remain caller responsibilities where applicable.

Memory and concurrency

Use the memory contract documented by this project. Shared-instance access is not claimed safe unless the repository explicitly provides a concurrency mode.

Build and configuration

The local repository provides its authoritative CMake/build configuration. Only supported integration paths shown there should be enabled.
