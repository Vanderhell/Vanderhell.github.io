Quick Start

This minimum pattern is adapted from the repository README or public-header examples. Comments state the expected behavior; no terminal output is fabricated.

#include "loxbudget.h"
static uint32_t mem[(LOXBUDGET_REQUIRED_SIZE(2,2,0)+3u)/4u];
loxbudget_t b; loxbudget_decision_t d;
loxbudget_op_profile_t p=loxbudget_op_profile_default(0);
if (loxbudget_init_simple(&b,mem,sizeof mem,2,2)!=LOXBUDGET_OK) return 1;
(void)loxbudget_set_resource(&b,0,10,LOXBUDGET_RES_REUSABLE);
(void)loxbudget_register_op(&b,&p);
(void)loxbudget_op_set_need(&b,0,0,5);
(void)loxbudget_check(&b,0,&d);
/* Expected: d.action == LOXBUDGET_ALLOW_FULL. */

Known limits

  • Not a scheduler, allocator, watchdog, logger or RTOS replacement
  • Policies and resource measurements are supplied by the application
  • The repository makes no safety-certification claim

Technical information

Public API and integration

Start with the public header shown in Quick Start and the repository documentation. Check every return value; storage, clock, transport and policy callbacks remain caller responsibilities where applicable.

Memory and concurrency

The repository documents no heap use for the library core; state is caller-owned. Shared-instance access is not claimed safe unless the repository explicitly provides a concurrency mode.

Build and configuration

The local repository provides its authoritative CMake/build configuration. Only supported integration paths shown there should be enabled.
