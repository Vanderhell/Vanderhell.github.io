Axiom One

A dependency-free static library of 22 independent embedded-focused primitives. Each has a plain C API and a bounded problem scope; the umbrella header is convenient, while static linking includes only referenced module objects.

Modules retain state in caller-owned objects where state is required. Modules do not allocate heap memory, perform I/O or acquire hidden time/random inputs. They provide no timer or callback service; ONEINIT explicitly runs the ordered function list supplied by its caller. Stateless helpers remain stateless; inputs, outputs, state updates and error results are explicit in each API contract.

Axiom One as a library

Composable, portable plain C building blocks for constrained systems. Caller-owned storage and state make ownership visible. Each operation accepts explicit inputs and returns explicit results; no hidden clock, random source or global mutable state is introduced by the modules.

Debug, Release, AddressSanitizer and MSVC warning-as-error test configurations are documented. A footprint report uses linker-map evidence for selected static library objects. These properties do not remove each module's documented domain, capacity or synchronization responsibilities.

Module details

ONEARB — Round-robin arbiter

Category
Scheduling
State
Stateful
Model
eligible bit mask → arbiter cursor → selected winner
Public API
one_arb_init, one_arb_next
Typical use
Select fairly among currently eligible bounded work items.
Limits
Caller initializes and retains arbiter state; winner exists only when an eligible request is selected.

ONEBACKOFF — Saturating exponential delay

Category
Retry timing
State
Stateless
Model
base delay + attempt + maximum → capped delay
Public API
one_backoff_delay
Typical use
Calculate a retry delay before passing it to an application timer.
Limits
Returns a bounded arithmetic delay; it does not schedule or wait.

ONEBUF — Single producer/consumer state buffer

Category
Buffer coordination
State
Stateful
Model
operation + capacity/value → buffer state → status and indices/generation
Public API
one_buf
Typical use
Coordinate a single producer/consumer handoff over caller-owned data.
Limits
Coordinates state only; payload storage and concurrency discipline belong to the caller.

ONEDBUF — Two-slot producer/consumer buffer

Category
Buffer coordination
State
Stateful
Model
operation + two-slot state → publish/release result
Public API
one_dbuf
Typical use
Publish a new value while retaining a ready slot or selecting documented drop-old policy.
Limits
Only coordination state is provided; the caller owns payload storage and synchronization context.

ONEDEAD — Dead-zone transform

Category
Signal conditioning
State
Stateless
Model
signed/unsigned sample + bounds → output
Public API
one_dead_u32, one_dead_i32
Typical use
Suppress small sensor deviations by mapping the configured interval to zero.
Limits
Configured interval and numeric type define the accepted domain.

ONEEMA — Integer exponential moving average

Category
Signal filtering
State
Stateful
Model
sample + EMA state → updated filtered value
Public API
one_ema_init, one_ema_update
Typical use
Smooth a noisy sampled sensor signal.
Limits
Caller owns initialized filter state; smoothing shift controls the documented integer update.

ONEFIELD — Packed fixed-width values

Category
Compact storage
State
Stateful descriptor
Model
range + width + caller bytes; ID/value → packed bytes or decoded value
Public API
one_field_init_range, one_field_set_u32, one_field_get_u32
Typical use
Store small configuration fields in a bounded byte array.
Limits
Backing storage is caller supplied and must meet the required size and range/width contract.

ONEHYST — Two-threshold hysteresis

Category
Signal conditioning
State
Stateful
Model
sample + low/high thresholds + binary state → updated state
Public API
one_hyst_i32, one_hyst_u32
Typical use
Prevent a threshold-controlled output from chattering near one boundary.
Limits
Requires low < high and state 0 or 1; state holds between thresholds.

ONEIDX — Numeric or symbolic key to index

Category
Lookup mapping
State
Stateful descriptor
Model
configured range/keys + ID/key → bounded slot index
Public API
one_idx_init_range, one_idx_index_u32
Typical use
Map stable IDs to offsets in an application-owned array.
Limits
Provides lookup mapping, not payload storage; caller defines the valid range or symbols.

ONEINIT — Ordered initialization runner

Category
Startup sequencing
State
Stateless
Model
ordered function array → invoke each function in order
Public API
one_init_run
Typical use
Express driver initialization before application initialization.
Limits
Runs supplied functions in order; initialization functions and their effects are caller-defined.

ONEOUTLIER — Accepted-sample delta guard

Category
Input validation
State
Stateful
Model
sample + accepted reference + max delta → accept/reject and reference update
Public API
one_outlier_init, one_outlier_accept
Typical use
Reject a sudden measurement outside the configured delta from the last accepted sample.
Limits
The initial accepted reference and maximum delta define the acceptance rule.

ONEQUANT — Nearest grid point

Category
Numeric conversion
State
Stateless
Model
signed/unsigned value + origin/step → snapped value
Public API
one_quant_i32, one_quant_u32
Typical use
Quantize a control or measurement value to a fixed increment.
Limits
Numeric types and step domain are part of the API contract.

ONERATE — Fractional event-rate generator

Category
Rate generation
State
Stateful
Model
numerator/denominator + phase → updated phase and emit flag
Public API
one_rate_step
Typical use
Generate an event on three of every ten calls without a fractional timer.
Limits
Caller retains phase; each call advances one deterministic phase step.

ONESCALE — Integer range conversion

Category
Numeric conversion
State
Stateless
Model
input range + output range + value → checked or clamped output
Public API
one_scale_u32 and signed/unsigned checked/clamp variants
Typical use
Convert a bounded ADC reading into a PWM range.
Limits
Checked forms report out-of-range input; clamp variants map to an endpoint.

ONESEQ — Cyclic sequence domain

Category
Sequence arithmetic
State
Stateful configuration
Model
bit width + sequence value → next/previous/distance/comparison
Public API
one_seq_init_bits, one_seq_next
Typical use
Advance an 8-bit sequence from 255 back to 0 with explicit cyclic rules.
Limits
Half-capacity distance is explicitly ambiguous; callers must check documented status.

ONESET — Packed membership set

Category
Bounded container
State
Stateful descriptor
Model
range + caller bytes; ID/key/index → add/remove/contains result
Public API
one_set_init_range, one_set_add_u32, one_set_contains_u32
Typical use
Track membership in a small fixed set without a general container.
Limits
Storage is caller allocated and sized through the required-byte API.

ONESLEW — Bounded step toward target

Category
Control signal
State
Stateless with caller value
Model
target + rise/fall limits + current value → bounded updated value
Public API
one_slew_i32, one_slew_u32
Typical use
Limit command movement per control-loop iteration.
Limits
Zero limit is a hold; the operation does not overshoot the target.

ONESTALE — Wrap-safe timestamp freshness

Category
Freshness check
State
Stateless
Model
now tick + updated tick + maximum age → fresh/stale result
Public API
one_stale_check
Typical use
Check freshness in a wrapping 32-bit tick counter.
Limits
Maximum age must be below 0x80000000 to avoid half-range ambiguity.

ONESTAT — Packed multi-field records

Category
Bounded records
State
Stateful descriptor
Model
record/field schema + caller bytes + operation → packed field result
Public API
one_stat_init_range, one_stat_get_u32, one_stat_add_u32
Typical use
Maintain compact bounded per-channel counters or small record sets.
Limits
Field widths, required byte capacity and saturating arithmetic follow the schema contract.

ONETRACE — Fixed-capacity ring trace

Category
Diagnostics
State
Stateful descriptor
Model
caller bytes + event → bounded ring; index → chronological entry
Public API
one_trace_init, one_trace_push, one_trace_get
Typical use
Retain a compact recent event history for failure diagnosis.
Limits
Storage and record width are caller supplied; pushing when full overwrites the oldest entry.

ONEVOTE — K-of-N sliding vote

Category
Filtering / voting
State
Stateful
Model
window size + threshold + boolean sample → rolling vote result
Public API
one_vote_init, one_vote_push
Typical use
Require three valid readings among the most recent five samples.
Limits
Window and threshold are configured and retained in caller-owned state.

ONEWINDOW — 32-packet replay window

Category
Protocol sequence filtering
State
Stateful
Model
packet sequence + 32-bit window state → new/duplicate/old/ambiguous classification
Public API
one_window_reset, one_window_accept
Typical use
Reject duplicate or too-old sequence numbers in a bounded packet receive window.
Limits
Packets older than 31 positions and half-range ambiguous sequences are classified explicitly.
