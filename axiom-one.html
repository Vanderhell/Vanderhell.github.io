02 / MATHEMATICAL PRIMITIVE

GrayGyre: a self-inverse placement transform

A compact index mapping for spreading nearby logical values across configured cells.

  1. Input: logical index
  2. Apply configured Gray-code shear
  3. Output: physical placement index
  4. Apply the same mapping again to recover the original
ALLOCATION-FREE · TABLE-FREE

Placement, not traversal

GrayGyre documents deterministic index placement for logical pages, banks and similar layouts. Its repository explicitly says the transform is not encryption, a hash, wear leveling, error correction or a full-cycle scheduler.

The repository reports physical ESP32-S3 performance measurements and separate compile/static validation for listed Cortex-M and RISC-V targets. Those records apply to GrayGyre’s documented configurations and do not establish hardware validation for the whole Axiom One family.

03 / IMPLICIT SEARCH

SkipSpace: navigate without storing the tree

A traversal primitive whose key design condition is whether compact state preserves future-relevant behavior.

Prefix→Sufficient state→Bounded subtree count→Visit or skip

SkipSpace keeps caller-owned navigation state and a fixed workspace. It updates a sufficient-state model, counts valid continuations with saturating arithmetic, and can skip a subtree without materializing every node.

Model boundary. Prefixes may share a state only when their future-relevant behavior is equivalent for the modeled problem. If the model needs more history, the state space can grow and the compression advantage can disappear. Counting and skip checks cost more than push/pop; the README recommends sparse skip checks for the described use.
