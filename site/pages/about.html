02 / EVIDENCE POLICY

Claims are scoped to what was inspected

Product pages distinguish repository-visible implementation, executed host tests, hardware validation, measured results, plans and unsupported behavior. Configured CI is not described as a passed run unless a corresponding result is available. A host test does not become hardware validation by being run against a platform adapter stub.

For audited products, the page links the reader to source documentation and records limitations such as unverified target media, incomplete parity, experimental guarantees or private implementation boundaries.

EVIDENCE LEVELS
source and API inspected
↓
host tests executed
↓
target or hardware evidence
↓
measured claim, with setup recorded
each level describes different evidence
