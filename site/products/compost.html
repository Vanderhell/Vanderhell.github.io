Compost

The project explores whether simple deterministic local rules can produce interesting global behavior in an artificial-life sandbox.

An experimental deterministic artificial-life simulator and complex-systems research project. Autonomous mathematical organisms consume binary input as FOOD, maintain internal state, energy and metabolism, grow structural bodies, hold territory, reproduce, die and compete for resources.

01 / SIMULATION MODEL

Local resource rules; global world behavior

Compost is an experimental deterministic artificial-life sandbox. It asks whether local rules for food, energy, growth, maintenance, territory, reproduction, death and resource competition can produce interesting global behavior without a central controller.

“Organism,” “food,” “body,” “metabolism,” “territory” and “death” are simulator abstractions. The repository does not claim biological realism, life, or evolutionary theory. Its outcomes are specific to implemented rules, parameters and input data.

local rules→resource interactions→world state→observed population and telemetry
02 / EXPERIMENT-OWNED INPUT

Binary files become FOOD in a sandbox world

Input files placed in an inbox are copied into experiment-owned storage and partitioned into FOOD. Runtime state and observations live in separate directories:

  • inbox/ — files supplied by the experimenter
  • world/ — prepared FOOD and persistent runtime state
  • telemetry/ — observation snapshots

The README advises using copies of files that the experimenter is willing to supply to a run. The input path is an experiment boundary, not a promise of nondestructive source handling.

03 / AUTONOMOUS RUNTIME

Organisms advance under local deterministic rules

The runtime models internal state, energy/reserves, metabolism, body structure, territory and competition. Reproduction and death are deterministic lifecycle transitions. World state persists while an autonomous experiment runs; observers report state without directing organism behavior.

These state transitions form an artificial-life model. The simulator's “energy” accounting is its own resource bookkeeping and should not be interpreted as a validated physical or biological energy model.

04 / READ-ONLY OBSERVATION

Telemetry describes the run; it does not control it

The status command can report FOOD accounting, population, body mass and bite sizes, organism reserves/debt/gut state, territories, corpses and runtime throughput. The README notes telemetry may be eventually consistent while workers are active.

PYTHON 3.11+BOUNDED OBSERVATION RUN
python -m pip install .
python -m mathematical_organism run sandbox --workers 4 --max-seconds 30
python -m mathematical_organism status sandbox --organisms
05 / REPRODUCIBILITY

Captured inputs and parameterized rules define an experiment

The repository contains captured one-minute runs under experiments/1m, described as intentional reproducibility artifacts rather than build output. A comparison should retain its input files, run parameters, version and artifacts. A deterministic implementation makes a fixed run replayable under matching conditions; it does not show that a particular observed pattern is general or statistically significant.

TEST SUITE
python -m pytest
06 / RESEARCH LIMITS

Interesting behavior is an observation, not proof

  • Compost is experimental and not a production data-processing system.
  • It is not a biological model and makes no evolutionary or scientific proof claim.
  • Population dynamics and performance scaling remain active research questions.
  • Results depend on the implemented rules, parameters and captured inputs.
  • Telemetry may be eventually consistent while workers run; observation does not direct the simulation.
